# FuzzlyFinder
Windows Fuzzy Finder to search your files/folders to find everything in one simple utility.
\n
Features:\n
Opens as a System Tray Icon in the Taskbar allowing another way to open and close the utility through the Right Click Context Menu.\n
Simple Hiding/Revealing/Closing of utility using global shortcuts. Works at any time. \n
Only 1 instance can run at a time. The utility detects running instances and prevents new ones from running.\n
Runs quietly in background using minimal resources until needed! (Never should be an issue. Pretty small program) \n
Detects system theme and sets the current theme accordingly.\n
Status Text shows current state of utility \n
\n
\n
Controls: \n
Single Click on path: Copies selected path to clipboard.\n
Double Click on path: opens file/folder path in explorer.exe\n
\n
Shortcuts:\n
Ctrl + Shift + F : Hides/Shows the search Window\n
Ctrl + Shift + X : Closes entire Program\n
